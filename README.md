# 🚀 CI/CD Pipeline Automation using GitHub Actions and Docker

## 📌 Project Overview

This project demonstrates a simple CI/CD pipeline using GitHub Actions and Docker.  
The application is containerized using Docker and automatically builds whenever code is pushed to the GitHub repository.

---

## 🛠️ Tech Stack

- Node.js
- Docker
- GitHub Actions
- GitHub

---

## ⚙️ Features

- Automated CI/CD workflow
- Dockerized Node.js application
- Automatic build process on code push
- Continuous Integration using GitHub Actions
- Lightweight and portable deployment
